# Alberto Clocks - Updated Project

This version keeps the existing Hero videos and adds a more structured product experience.

## Main updates
- Premium Midnight Navy / Ice Blue / Silver visual direction with subtle gold accents.
- Improved responsive navbar and mobile drawer.
- Products now start with clickable category cards.
- All Watches + Vintage + Luxury + Smart + Classic + Sports + Automatic filtering.
- Product sorting: Latest Watches, Most Popular, Price High to Low, Price Low to High.
- Show More / Show Less.
- Product details modal.
- Product data moved to JSON.
- Added four Watch Packages.
- Existing Hero video rotation remains unchanged.
- Added `VIDEO_GUIDE.md` explaining exactly where to add future videos.
- Existing Technology, Gallery, About, Store Locator, Support, Contact, Sell Watch and Footer remain in the project flow.

## Run
After extracting:
1. Open the project folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.

Do not copy `node_modules` from the ZIP. It is intentionally excluded so npm can install dependencies for your own Windows environment.
